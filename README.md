
# 🚀 ViralZIA - AI Video Production Suite

![ViralZIA Banner](https://img.shields.io/badge/AI-Powered-purple?style=for-the-badge) ![Status](https://img.shields.io/badge/Status-Cloud_Production-green?style=for-the-badge) ![Stack](https://img.shields.io/badge/Tech-React_|_Supabase_|_Google_VEO-blue?style=for-the-badge)

**ViralZIA** es la plataforma definitiva para creadores de contenido. No es solo un generador de texto; es un **estudio de producción generativa en la nube**. 

Desde una simple idea hasta un video renderizado listo para TikTok, todo sucede gracias a la Inteligencia Artificial.

---

## ✨ Poderes Actuales

### 🎥 Producción de Video con IA
*   **Google VEO Integrado:** Genera videos cinematográficos reales (MP4) a partir de texto o imágenes.
*   **Storyboard IA:** Genera secuencias de imágenes consistentes con Imagen 4.0 y modelos Nano rápidos.
*   **Voz Neuronal:** Genera narraciones de audio realistas con múltiples voces (Gemini TTS).

### 🧠 Cerebro Estratégico
*   **Mentor IA:** Un consultor experto disponible 24/7 que conoce el contexto de tus proyectos.
*   **Radar de Tendencias:** Analiza PDFs, URLs y búsquedas en vivo para encontrar tu próximo hit viral.
*   **Kit de Marca:** Define tu ADN una vez (Tono, Estilo, Audiencia) y la IA lo respetará en cada generación.

### ☁️ Arquitectura Cloud (SaaS)
*   **Supabase Backend:** Autenticación segura, base de datos PostgreSQL en tiempo real y Edge Functions para operaciones sensibles.
*   **Colaboración:** Sistema de gestión de usuarios con invitaciones controladas por administrador.
*   **Autoguardado:** Tu trabajo está seguro en la nube. Empieza en el móvil, termina en el escritorio.

### 🔗 Ecosistema Conectado
*   **Integración OAuth:** Conecta tus cuentas de TikTok, YouTube e Instagram de forma segura.
*   **Viralizador:** Generación automática de metadatos SEO y Hooks virales.
*   **BYOK (Bring Your Own Key):** Usa tu propia API Key de Google para control total y acceso a modelos VEO.

---

## 🛠️ Stack Tecnológico

*   **Frontend:** React 19, TypeScript, Vite, Tailwind CSS.
*   **Estado:** Zustand.
*   **Backend (BaaS):** Supabase (Auth, DB, Edge Functions).
*   **AI Models:**
    *   `veo-3.1` (Video Generation)
    *   `gemini-2.5-pro` (Reasoning & Scripting)
    *   `imagen-4.0` (High Fidelity Images)
    *   `gemini-tts` (Neural Voice)

---

## 🚀 Despliegue Rápido

1.  **Base de Datos:** Ejecuta `supabase/schema.sql` en tu proyecto de Supabase.
2.  **Funciones:** Despliega las Edge Functions con `npx supabase functions deploy`.
3.  **Frontend:** Despliega en Vercel/Netlify configurando las variables de entorno.
